# Travel Buddy V1.0

Website and interactive iPhone demo release, 2 November 2026. Package version 1.0.0; native marketing version 1.0, build 1.

- iPhone-sized interactive preview, with Today, Plan & explore, My trips, and compact travel tools.
- Shared final budget: selected flights, stays and rental cars replace their estimates; group, per-person, daily and remaining totals stay connected.
- On-trip itinerary, done/skipped stops, notes, essentials, packing and spending stored on the device.
- Licensed Lisbon activity photos bundled locally, including every curated itinerary stop.
- Discovery preserves verified matches when a different location lookup fails, limits stalled geographic searches, and avoids automatic searches when changing browser focus.

Public links:
- Website: https://wjlmaggie-sudo.github.io/your-travel-buddy/
- iPhone demo: https://wjlmaggie-sudo.github.io/your-travel-buddy/iphone-demo.html
- Full-screen app demo: https://wjlmaggie-sudo.github.io/your-travel-buddy/app-demo/#/on-trip

This release contains the website, browser demo and native iOS source. It does not include an installable IPA or App Store/TestFlight release. Xcode is not installed on the development Mac; native compilation, signing and device/plugin verification remain pending. Native backend-origin and auth callback setup remain pending as recorded in IPHONE_APP.md. Public discovery still depends on third-party geographic/weather availability and supports travel phrases rather than general AI conversation. Unavailable images outside the bundled Lisbon guide show an honest placeholder.
