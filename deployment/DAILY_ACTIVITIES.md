# Daily activities and backup places

Generated starter and persona plans include three sightseeing/experience slots in addition to meals, rest, work and travel. Curated and directory names are used when available; missing coverage stays explicitly unverified instead of inventing venues. Business work blocks and family rest breaks are retained. Existing edited plans are never overwritten automatically; the overview offers a review/rebuild prompt for older guest plans.

The day itinerary appears before optional recommendations. Three backup cards are expanded by default in guest, draft and saved-trip views, with more available on request. Backups exclude the selected day's current visits; places on other days can appear as alternatives. Adding remains explicit, preserves existing budgets, and respects the existing daily capacity. Sparse/offline directories show an honest explanation.

Sintra's third curated stop is Vila Sassetti gardens, using the official operator's location and visit reference: https://www.parquesdesintra.pt/en/parks-monuments/villa-sassetti/ (checked 30 October 2026). This keeps the third stop in Sintra rather than filling the day from Lisbon city centre.

Validation: TypeScript, targeted planning/persona/directory/day-map/backup tests, saved-trip creation tests, and guest backup-addition/refresh regression. No new paid service, API key or database migration is required.
